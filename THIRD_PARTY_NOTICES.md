# Third-party software

rac1-native's own code is under the MIT licence (`LICENSE`). It uses the libraries below, each
under its own licence. None of them is copyleft.

## Downloaded at build time

CMake downloads these when the project is configured (`cmake/dependencies.cmake`), each pinned
to a release and checked against its SHA-256. They are not stored in this repository.

| Library | Version | Licence | Used for |
|---|---|---|---|
| [GLFW](https://github.com/glfw/glfw) | 3.4 | zlib | window, OpenGL context, keyboard, mouse and gamepad |
| [GLM](https://github.com/g-truc/glm) | 1.0.1 | MIT | vector and matrix math |
| [Dear ImGui](https://github.com/ocornut/imgui) | 1.91.4 (docking) | MIT | the menus' and the debug tools' widgets |
| [TinyGLTF](https://github.com/syoyo/tinygltf) | 2.9.7 | MIT | glTF model loading; bundles [nlohmann/json](https://github.com/nlohmann/json) (MIT) and [stb_image](https://github.com/nothings/stb) (public domain / MIT) |
| [miniaudio](https://github.com/mackron/miniaudio) | 0.11.25 | public domain / MIT-0 | audio output |
| [Vulkan-Headers](https://github.com/KhronosGroup/Vulkan-Headers) | 1.3.296 | Apache-2.0 / MIT | the experimental Vulkan renderer: the API's headers |
| [volk](https://github.com/zeux/volk) | 1.3.296.0 | MIT | the experimental Vulkan renderer: its function loader (no Vulkan SDK needed to build) |

The Vulkan renderer's shaders are compiled at build time by `glslc` ([shaderc](https://github.com/google/shaderc), Apache-2.0)
or `glslangValidator` ([glslang](https://github.com/KhronosGroup/glslang), BSD-3-Clause / Apache-2.0) when one is installed:
build tools only, nothing of them is linked or shipped.

These are stored in the repository, each with its licence next to it.

## Code derived from other projects

- `runtime/gs/gs_emu.cpp`: the GS local-memory layout tables, as OpenGOAL's
  `common/texture/texture_conversion.h` has them (ISC, © OpenGOAL Team).
- `runtime/iop/snd989_stream.cpp`: the stream voices' volume formulas, after OpenGOAL's 989snd
  (`VoiceManager::MakeVolume` / `AdjustVolToGroup` in `vagvoice.cpp`; ISC, © OpenGOAL Team).
- `src/formats/sound_bank.cpp`: the SPU pitch tables and the note-to-pitch conversion, the same as
  OpenGOAL's 989snd `util.cpp` (`NotePitchTable`, `sceSdNote2Pitch`; ISC, © OpenGOAL Team).

## System libraries

The project links these from the player's system and does not include them.

- **OpenGL**, **X11** (with Xrandr, Xinerama, Xcursor, XInput, Xext) and **Wayland** (with
  xkbcommon): required. GLFW is built for both X11 and Wayland and picks one when the game starts.
- **FFmpeg** (libavcodec, libavutil), optional, found with pkg-config, decodes the game's movies. It
  is LGPL 2.1+ (or GPL, depending on how it was built). Without FFmpeg, the game runs and skips the
  movies.

## Not included

Nothing from Ratchet & Clank, the PS2 or Sony. All the game's data is generated from the
player's own disc at setup time.
