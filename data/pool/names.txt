# The asset pool's names (the open engine, docs/open-engine.md): a stable name for a class of a game level, for a level
# mod's `import <name>` lines (level.txt) and a plugin's import services (docs/sdk.md). A name never changes once given;
# a class without one is named `<level>:<class>`. Names are ours (what the class is or does in play), the numbers the game's.
# <name> <level>:<class> <what it is>
