# <image>:<address>[-<end>] <tag> [<package>] <description>
#   image: L0..L18 (a level's overlay, L0 Veldin's, the reference), front (the boot module), core (the boot executable's
#   libraries); a range covers the functions that start in it. A note applies to every copy of the function's body.
#   tag:
#     host        replaced by host code or the runtime layer on purpose (hardware, DMA, GS packets, the kernel): not to port
#     debug       a development feature of the original (a debug camera or mode the retail game never turns on)
#     inline      covered by its callers' ports (written into them, or a helper with a register ABI)
#     inprogress  being ported on another branch
#     latent      reached in a normal playthrough and not ported: a bug a player can meet
#     check       reachable through a table or a pointer, not seen in the headless tour: to verify
#     wire        ported for another level (the same code): only the registration / variants row is missing
#     review      the level's own build differs from the Veldin port that runs in its place: to compare (per-level oracle)
#     false       not a function (a data word that looks like a code pointer, a jump table's case)
#     cut         cut content: nothing reaches it (see the cut content section)
#     unopened    named only by menu data that no code opens where it is (the title's pages in the levels' overlays, widgets no page lists)
#   package: P1..P9 (the proposed work packages, docs/port-inventory.md)
#
# Addresses, sizes and our descriptions only: never the game's code or text.
